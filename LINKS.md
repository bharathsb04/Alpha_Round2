## ⚡ Quick Server Launch Commands

### 1. Start Python Backend (FastAPI + Uvicorn)
```bash
cd backend
py -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 2. Start Frontend Web Server (Vite + React)
```bash
cd frontend
npm.cmd run dev
```
